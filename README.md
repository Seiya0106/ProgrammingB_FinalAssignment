# ProgrammingB_FinalAssignment
プログラミング演習Bの最終課題で使うリポジトリです

### 実行方法
```zsh
python3 main.py
```

### ゲームの概要
早押しゲームです。素早くボタンを見つけてボタンを押すまでのタイムを競います。

### マニュアル
* 左クリック：ボタン押す
* Rキー：リスタート

### 工夫した点
* 状態管理をクラスを使って管理したこと
* モジュール分割して、ファイルごとに役割を分けている点
* 1から全て自分の力で作成した点
* ゲームそのもの
    * カウントダウンを入れることで、急にゲームが始まらないようにしたこと
    * リトライ機能を入れることで、簡単に何度でもやり直せるようにしたこと

### 苦労した点
* どの機能をどのクラスに持たせるか悩んだこと
* 何を１つのファイルにまとめるかなどのモジュール分割に苦労したこと
* クラス名やファイル名の名前をどう定義したらわかりやすくなるか考えたこと
