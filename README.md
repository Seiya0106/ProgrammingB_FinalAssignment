# ProgrammingB_FinalAssignment
プログラミング演習Bの最終課題で使うリポジトリです

### 実行方法
```zsh
python3 main.py
```

### ゲームの概要
早押しゲームです。素早くボタンを見つけてボタンを押すまでのタイムを競います。

### マニュアル
* 左クリック：ボタン押す
* Rキー：リスタート

### 工夫した点
* 状態管理をクラスを使って管理した
* モジュール分割して、ファイルごとに役割を分けた
* サンプルゲームなど元となるコードを使用せず、1から作った
* ゲームそのもの
    * カウントダウンを入れることで、急にゲームが始まらないようにした
    * リトライ機能を入れることで、簡単に何度でもやり直せるようにした
    * 左クリックを押した瞬間にだけ反応するようにした

### 苦労した点
* どの機能をどのクラスに持たせるか悩んだ
* 何を１つのファイルにまとめるかなどのモジュール分割に苦労した
* クラス名やファイル名の名前をどう定義したらわかりやすくなるか考えた

### AI使用
* カウントダウン・ゲームプレイ中・ゲームクリアのゲーム状態の遷移をクラスで分けて管理する方法を教えてもらった
* マウスの左クリックを押した瞬間だけ検知する方法がわからなかったので、AIに書いてもらった
* クリアタイムの計測方法がわからなかったので、AIに書いてもらった
